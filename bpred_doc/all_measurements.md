# SCR1: предсказатель переходов — все измерения (сводка)

Единый справочник по всем замерам предсказателя. Условия, если не сказано иное:
verilator 5.020, `CFG=RV32IMC_MAX`, все прогоны CRC/verify-проверены. Циклы — полный
прогон, меньше лучше; Δ — снижение относительно указанной базы. Детальные разборы:
[optimization_study.md](optimization_study.md), [embench_suite.md](embench_suite.md),
[trace_accuracy.md](trace_accuracy.md), [board_silicon_matrix.md](board_silicon_matrix.md),
[recommended_config.md](recommended_config.md).

## 5. Точность направления (эталонная модель, 5.03M условных веток)

| алгоритм | accuracy | mispred |
|---|---|---|
| always-NT (No-BPU) | 44.2 % | 2 805 652 |
| **bimodal-2b (BHT SCR1)** | **87.9 %** | 610 929 |
| gshare-10b (1024) | 90.9 % | 456 999 |
| local-2level | 92.5 % | 376 563 |
| gshare-16b / 64K (потолок) | 96.4 % | 179 747 |

Запас 87.9 → 96.4 % — ёмкость/алиасинг, не алгоритм; в циклы не конвертируется.

### 5.1 Против SoTA — CBP-NG трейс `gcc_test` (493K условных веток)
| предсказатель | память | accuracy | mispred |
|---|---|---|---|
| bimodal-2b (BHT SCR1) | ~2 Кбит | 91.4 % | 42 322 |
| gshare-64K (потолок схемы) | 128 Кбит | 94.0 % | 29 799 |
| **TAGE-SC-L (SoTA)** | **1531 Кбит** | **98.0 %** | 9 845 |

Наш BHT — 91.4 % за ~2 Кбит; TAGE — 98 % за ×750 памяти. На SCR1 разрыв бесполезен
(точность не конвертируется).
